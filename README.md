# 🫂 Sahaara AI
**AI-Powered Dynamic Mental Health Monitoring & Early Intervention System**

A digital wellbeing support platform built with Streamlit designed to identify worsening distress indicators early, track trends, and facilitate connections with human professional review.

---

## 🌟 Modules & Features

1. **🏠 Home**: Overview of the platform, architecture workflow, and quick-start actions.
2. **🧠 AI Assessment**: Multi-dimensional wellbeing evaluation covering emotional health, sleep, anxiety, stress, social connectivity, feelings of helplessness, immediate safety, and optional qualitative check-ins.
3. **📈 Wellbeing Trend**: Historical distress tracking, point-in-time delta alerts, and downloadable CSV reports.
4. **🛡️ Case Journey**: Tailored tracking across legal, rehabilitation, and long-term recovery stages.
5. **👩‍⚕️ Professional Connect**: Directory of vetted professionals and trusted personal support contact management.
6. **📊 Counsellor Dashboard**: Aggregated triage view with priority metrics and distress level breakdowns.
7. **🌍 Resilience Support**: Climate & external crisis context logging (e.g., floods, heatwaves, community stress).
8. **🔐 Privacy & Safety**: Responsible AI safeguards, consent framing, and safety notices.

## 🚀 Getting Started

### 1. Install Dependencies
```bash
pip install -r requirements.txt
```

### 2. Run the Application
```bash
streamlit run app.py
```
